### Findings

FINDING: prelude.llt:3383 uses [raise ev.errors] — same bug as the 5 fixed
locations, missed in the second-pass fix. The eval-program function in prelude
calls [raise ev.errors] where ev.errors is now a Dict {0: String(message)}.
The prelude raise function is defined as:
  raise: [fn@Never [let msg@String] [builtin-raise msg]]
The @String runtime type assertion on msg causes TypeAssertFailed
("expected String, got Dict") instead of raising the original eval error
message. The original builtin-eval failure is silently replaced by a confusing
secondary type-mismatch error.

Fix: Change [raise ev.errors] to [raise [get 0 ev.errors]] or equivalently
[builtin-raise [builtin-get 0 ev.errors]] to match the other 5 fixed sites.
| SCOPE: fix-now
| FILE: stdlib/prelude.llt:3383
