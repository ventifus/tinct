### Verdict

REQUEST_CHANGES

Two fix-now correctness bugs must be addressed before merge:

1. **bas.rs:515-516** — `typed_variadics`/`rest` use structural equality instead of contravariant subtype recursion in BAS atom-subtype Function-Function arm. This directly violates the standard function subtyping rule (contravariant params, covariant return) for the new fields. It means subtype relationships involving typed-variadic functions produce incorrect results from `is_subtype`, which propagates to narrowing, TypeAssert validation, and constraint solving.

2. **typecheck_cek.rs:2171-2174** — `finalize_call_no_positional_args` still uses `saturating_sub(1)` for `min_required`, inconsistent with `apply_call_args_poly` which was correctly fixed in this sprint. With `required_count` now correctly counting only fixed params, the subtraction produces wrong arity bounds for variadic functions at named-arg-only call sites.

Finding 3 (error message nit) is also fix-now per review protocol: nits do not accumulate.
