# strings

### `pad-left`

Left-pad a string to a target width with a padding character

```tinct
fn@String [s@String width@Int pad-char@String]
```

### `pad-right`

Right-pad a string to a target width with a padding character

```tinct
fn@String [s@String width@Int pad-char@String]
```

### `str-reverse`

Reverse a string by characters

```tinct
fn@String [s@String]
```
